# Xen'drik Hexcrawl & Journeys — v0.1.6.2

- Travel conditions use Foundry roll messages for Dice So Nice animation.
- Explicit tracking DC changes in condition chat cards.
- Optional alternative exhaustion in **Game Settings → Configure Settings** (world scope, off by default; reload required).
- Uses D&D 5e's native exhaustion pips, extended from 6 to 10 by adjusting system condition configuration; no injected sheet controls.
- Native exhaustion roll reduction becomes −1 per level with no speed penalty, and death at level 10.
- Prepared spell and ability DCs receive a −1 per level adjustment for character and NPC actors.

**Compatibility:** This is an untested Foundry v14/D&D 5e v6.1.1 integration. Verify on a backup world. Third-party item DCs and sheet variants may require additional handling. Repository source updates do not automatically publish a GitHub Release ZIP.
