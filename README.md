# Xen’drik Hexcrawl & Journeys — v0.1.6 beta

- Travel conditions roll 1d10 using Foundry roll messages (Dice So Nice compatible).
- Chat explicitly states raised/lowered/unchanged tracking DC and old/new DC.
- World-wide optional alternative exhaustion toggle in Journey Manager, off by default.
- 0–10 exhaustion bubbles on compatible actor sheets, with actor-backed updates.
- Experimental D&D 5e pre-roll hook penalty integration for mutable roll configurations.

**Compatibility warning:** Native D&D exhaustion penalties, spell DC overrides, Midi-QOL and other automation have NOT been verified in a running Foundry v14/dnd5e v6.6 instance. In particular, spell save DC changes and suppressing default exhaustion effects are not yet guaranteed. Test on a backup world before enabling the option.
